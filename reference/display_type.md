# Shiny app display mode helper

Shiny app display mode helper

## Usage

``` r
display_type(run = "w")
```

## Arguments

- run:

  where to launch app:

  - `"p"` = launch in viewer pane

  - `"b"` = launch in external browser

  - `"w"` = launch in window (default)

## Value

notification of `shinyViewerType` option
